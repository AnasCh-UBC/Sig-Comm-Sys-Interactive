1What is a system?

Definition

A system is an interconnection of elements or devices that, when excited by an input signal, responds by producing an output signal.

Examples:
Electric circuit

Input: Voltage source; Output: Current through a wire (e.g., an amplifier or an RC circuit).

Drum

Input: Drumstick stroke; Output: Beat sound.

Whistle

Input: Steady flow of air; Output: Pure musical tone.

To characterize a system we model the relation between its input and output, called the input–output relation: $$y(t)=\mathcal{T}[x(t)].$$

Input \(x(t)\) Excitation
→
System \(\mathcal{T}[\cdot]\) The operation performed
→
Output \(y(t)\) Response

Three simple systems

Use the interactive example below to experiment with the following systems:

Differentiator \[\mathcal{T}[x(t)]=\dfrac{d}{dt}x(t)\].
Amplifier \[\mathcal{T}[x(t)]=a\,x(t)\].
Lowpass filter, cutoff freq. $f_c$ $x(t)=\cos(2\pi f_0 t)$ $\Rightarrow$ \[\mathcal{T}[x(t)]=\begin{cases} x(t),& f_0\lt f_c\\ 0, &f_0\geq f_c\end{cases}\]

2Classifying systems

A system can be classified according to four properties:

Discrete-time or continuous-time

Linear or nonlinear

Time invariant or time variant

Causal or noncausal

Select a property to explore its definition and examples.

Discrete-time vs. continuous-time

Discrete-time system

Processes discrete-time signals.

\[x[n] \text{ processed into } y[n]\]
Example: Discrete-time differentiator \[ y[n]=x[n]-x[n-1] \] Both x and y are indexed by an integer \(n\).
Continuous-time system

Processes continuous-time signals.

\[x(t) \text{ processed into } y(t)\]
Example: Continuous-time differentiator \[ y(t)=\frac{d}{dt}x(t) \] Both x and y are indexed by a real number \(t\).

Linear vs. nonlinear

Linear system

Satisfies superposition and homogeneity

\[ \mathcal{T}[a_1x_1(t)+a_2x_2(t)] = a_1\mathcal{T}[x_1(t)] + a_2\mathcal{T}[x_2(t)] \]
Example: Continuous-time differentiator \[ y(t)=\frac{d}{dt}x(t) \] \(\frac{d}{dt}(a_1x_1(t)+a_2x_2(t))=a_1\frac{d}{dt}x_1(t)+a_2\frac{d}{dt}x_2(t)\).
Nonlinear system

Does not satisfy superposition and homogeneity.

\[ \mathcal{T}[a_1x_1(t)+a_2x_2(t)] \neq a_1\mathcal{T}[x_1(t)] + a_2\mathcal{T}[x_2(t)] \]
Exmaple: Squaring \[ y(t)=x^2(t) \] \((a_1x_1(t)+a_2x_2(t))^2\neq a_1x_1^2(t)+a_2x_2^2(t)\) in general.

Time-invariant vs. time-variant

Time-invariant system

Delaying input by \(t_0\) delays output by \(t_0\)

\[ \mathcal{T}[x(t)]=y(t)\Rightarrow\mathcal{T}[x(t-t_0)]=y(t-t_0)\]
Example: Amplifier \[ y(t)=a\,x(t) \] Input \(x(t-t_0)\) produces output \(a\,x(t-t_0)=y(t-t_0)\).
Time-variant system

Does not satisfy time-invatiance

\[ \mathcal{T}[x(t)]=y(t) \nRightarrow \mathcal{T}[x(t-t_0)]=y(t-t_0)\]
Example: Modulator \[ y(t)=x(t)\cos(2\pi f_0t) \] Input \(x(t-t_0)\), output \(x(t-t_0)\cos(2\pi f_0t)\neq y(t-t_0)\).

Causal vs. noncausal

Causal system

Output at \(t=t_0\) depends only on input at \(t\leq t_0\).

\[ y(t_0)=\mathcal{T}[x(t):t\leq t_0] \]
Example: Modulator \[ y(t)=x(t)\cos(2\pi f_0t) \] Output at \(t_0\) depends only on input at \(t_0\).
Noncausal system

Output at \(t=t_0\) can depend on input at \(t>t_0\)

\[ y(t_0)\neq \mathcal{T}[x(t):t\leq t_0]\text{ in general} \]
Example: \[ y(t)=x(t-2)+x(t+2) \] Output at \(t_0\) depends on input at \(t_0+2\) (future input).

3LTI systems and convolution

Many systems in communications are modeled as linear time-invariant systems

A linear time-invariant (LTI) system is a system that is both linear and time-invariant.
Impulse response
An LTI system is fully characterized by its impulse response $h(t)$, i.e., the output of the system when the input is an impulse $\delta(t)$.
An LTI system is causal if and only if its impulse response $h(t)$ is a causal signal, i.e., $h(t)=0$ for $t\lt 0$.
Causal LTI systems: a linear time-invariant (LTI) system is causal if and only if its response to an impulse $\delta(t)$, the impulse response $h(t)$, is a causal signal ($h(t)=0$ for $t<0$).

An LTI system is both linear and time-invariant.

Question: if the output for $\delta(t)$ is $h(t)$, what is the output for a general input $x(t)$?

Why the answer is a convolution

  1. Any input is a sum of weighted, shifted impulses (sampling property): $x(t)=\displaystyle\int_{-\infty}^{\infty}x(\tau)\delta(t-\tau)\,d\tau$.
  2. Time invariance: the impulse $\delta(t-\tau)$ produces the shifted response $h(t-\tau)$.
  3. Linearity: weighting and summing the inputs weights and sums the outputs.
$$y(t)=x(t)\circledast h(t)=\int_{-\infty}^{\infty}x(\tau)\,h(t-\tau)\,d\tau$$

Slide the spacing $\Delta$ below to build the output from impulses: the sum of scaled, delayed copies of $h(t)$ converges to the convolution as the impulses get denser.

4Properties of convolution

Flip, shift, multiply, integrate

How to evaluate and plot $y(t)=x(t)\circledast h(t)$

  1. Draw both $x(\tau)$ and $h(\tau)$ with respect to $\tau$.
  2. Flip $h(\tau)$ and shift by $t$ to obtain $h(t-\tau)$, and plot the result.
  3. Multiply and integrate with respect to $\tau$: the area under $x(\tau)h(t-\tau)$ is $y(t)$.
  4. Repeat for every $t$.
Example · step input, decaying-exponential system

Let $x(t)=u(t)$ and $h(t)=e^{-at}u(t)$ with $a>0$. Find $y(t)=x(t)\circledast h(t)$. (Pick $x=$ Step and $h=$ Decaying in the widget to see it.)

Show solution

For $t<0$, $h(t-\tau)$ lies entirely where $x(\tau)=0$, so the product is zero and $y(t)=0$. For $t\ge0$ the product is nonzero on $0\le\tau\le t$: $$y(t)=\int_0^t e^{-a(t-\tau)}d\tau=e^{-at}\int_0^t e^{a\tau}d\tau=\frac{1}{a}\left(1-e^{-at}\right).$$ So $y(t)=0$ for $t<0$ and $y(t)=\tfrac{1}{a}(1-e^{-at})$ for $t\ge0$.

Properties of convolution

Commutativity

$x(t)\circledast y(t)=y(t)\circledast x(t)$

Associativity

$x\circledast(y_1\circledast y_2)=(x\circledast y_1)\circledast y_2$

Distributivity

$x\circledast(y_1+y_2)=x\circledast y_1+x\circledast y_2$

Identity element

$x(t)\circledast\delta(t)=x(t)$

(Proofs are in the exercises.) The dashed red curve in the widget above is $h\circledast x$ with the roles swapped: it lands exactly on $x\circledast h$.

You should be able to express and plot the convolution of two signals.

5Eigenfunctions of LTI systems

Complex sinusoids pass through LTI systems unchanged in shape

For an LTI system with impulse response $h(t)$ and a complex sinusoidal input $x(t)=e^{j(2\pi f_0t+\theta)}$, the output is $$y(t)=x(t)\circledast h(t)=e^{j(2\pi f_0t+\theta)}H(f_0),\qquad H(f_0)=\int_{-\infty}^{\infty}h(\tau)e^{-j2\pi f_0\tau}d\tau.$$ (Proof in exercises.) The response to a complex sinusoid is a complex sinusoid with the same frequency, scaled by $|H(f_0)|$ and phase-shifted by $\angle H(f_0)$. For this reason complex sinusoids are called eigenfunctions of LTI systems.

The widget feeds a cosine (the real part of a complex sinusoid) through $h(t)=e^{-at}u(t)$, for which $H(f)=1/(a+j2\pi f)$.

Key results

  • A system maps $x(t)$ to $y(t)=\mathcal{T}[x(t)]$; classify it as linear, time-invariant and causal.
  • An LTI system is determined by $h(t)$ and $y=x\circledast h$.
  • Convolution is commutative, associative and distributive, with $\delta(t)$ as identity.
  • Complex sinusoids are eigenfunctions: $e^{j2\pi f_0t}\to H(f_0)e^{j2\pi f_0t}$.
