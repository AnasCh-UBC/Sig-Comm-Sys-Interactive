This page summarizes the preliminary material you should know from previous courses, and repeats some of the key topics from the review lectures on signals and systems (Lectures 2 and 3). Review it carefully: it is required for solving problems in APSC 270.

Learning objectives

  • Recognize and sketch the common signals: sinusoids, \(\Pi(t)\), \(\Lambda(t)\), \(\operatorname{sinc}(t)\), \(u(t)\), \(\delta(t)\), and \(\operatorname{sign}(t)\).
  • Apply shifting, time-scaling, and time-reversal, alone and combined.
  • Compute the energy and power of a signal: \(E_x = \int_{-\infty}^{\infty}|x(t)|^2\,dt\).
  • Classify a system as linear, time-invariant, and causal, and compute the convolution: \[ y(t)=x(t)\circledast h(t) =\int_{-\infty}^{\infty}x(\tau)h(t-\tau)\,d\tau. \]
  • Use trigonometric identities, Euler's formula \(e^{j\theta}=\cos(\theta)+j\sin(\theta)\), and small-angle approximations.

2Some important signal operations

Shifting, time-scaling and time-reversal

  • Shift: \(x(t-t_0)\) is \(x(t)\) shifted to the right by \(t_0\) if \(t_0>0\), and to the left if \(t_0<0\).
  • Scale: \(x(at)\), \(a>0\), is contracted along the time axis if \(a>1\) and expanded if \( 0
  • Reverse: \(x(-t)\) is \(x(t)\) flipped about the vertical axis.

Operations can be combined with each other and with amplitude scaling, addition and multiplication. The playground below builds \(y(t) = Ax(\pm a(t - t_0))\); try one operation at a time first.

Example 2.1 · Combining operations

Plot \(x(t) = 2\Pi((t − 1)/2)\). Use the button above to load it, then check against the solution.

Show solution

Start from \(\Pi(t)\), a unit pulse centred at t = 0 with width 1. Shifting right by 1 moves the centre to t = 1; the factor ½ inside expands the width to 2; the factor 2 doubles the height. Check by evaluating: \(\Pi(s) = 0\) for \(|s| > ½\), so \(\Pi((t − 1)/2) = 0\) when \((t − 1)/2 < −½ \) or \(> ½\), i.e. \(t< 0\) or \(t> 2\), and it equals 1 for \(0 \leq t \leq 2\). Hence \(x(t)\) is a pulse of height 2 on [0, 2].

3Signal energy and power

Which signals have finite energy, and which have finite power?

\[ \begin{aligned} E &= \lim_{T\to\infty} \int_{-T/2}^{T/2}|x(t)|^2\,dt \\[10pt] P &= \lim_{T\to\infty} \frac{1}{T} \int_{-T/2}^{T/2}|x(t)|^2\,dt \\[10pt] P &= \frac{1}{T_0} \int_{-T_0/2}^{T_0/2}|x(t)|^2\,dt \qquad \text{(periodic with period \(T_0\))} \end{aligned} \]

These expressions are unitless, which keeps them general. If the signal is a current in amperes through a load of 1 Ω, then P is in watts. Use the window slider to see the limit in action: for an energy signal \(E_T\) settles while \(P_T\to 0\); for a power signal \(E_T\) keeps growing while \(P\) settles.

4LTI systems and convolution

Linearity, time invariance, causality, and the impulse response

Let the output for input xi(t) be yi(t).

  • Linearity: input a1x1 + a2x2 gives a1y1 + a2y2.
  • Time invariance: x(t − t0) gives y(t − t0) for any t0: a delayed input produces a delayed output.
  • Causality: y(t0) depends only on x(t) for t ≤ t0.

Pick a system and test it: the top plot checks time invariance (do the two curves coincide?), the bottom plot checks superposition.

A system that is both linear and time-invariant is an LTI system, characterized by its impulse response h(t) (its output for input δ(t)). Its output for any input is the convolution

y(t) = x(t) ⊛ h(t) = ∫−∞∞ x(τ) h(t − τ) dτ

To evaluate it: (1) plot x(τ) and h(τ); (2) plot the time-reversed h(−τ); (3) shift it by t to get h(t − τ); (4) multiply by x(τ) and integrate over τ; (5) repeat for all t.

Example 4.1 · Step input, decaying-exponential system

Let x(t) = u(t) and h(t) = e−atu(t), a ≥ 0. Find y(t) = x(t) ⊛ h(t).

Show solution

The shape of x(τ) tells us which cases to consider. For t < 0, h(t − τ) lies entirely where x(τ) = 0, so the product is zero and y(t) = 0. For t ≥ 0 the product is nonzero for 0 ≤ τ ≤ t:

y(t) = ∫0t e−a(t−τ) dτ = e−at ∫0t eaτ dτ = e−at eat − 1a = 1a(1 − e−at)

So y(t) = 0 for t < 0 and (1/a)(1 − e−at) for t ≥ 0. Compare with the bottom plot of the widget above.

5Trigonometric identities and calculus

Identities used throughout APSC 270

2 cosa cosb = cos(a−b) + cos(a+b)  ·  2 sina sinb = cos(a−b) − cos(a+b)  ·  2 sina cosb = sin(a−b) + sin(a+b)
sin(a±b) = sina cosb ± cosa sinb  ·  cos(a±b) = cosa cosb ∓ sina sinb
cos²a = (1 + cos 2a)/2  ·  sin²a = (1 − cos 2a)/2  ·  cosa = sin(a + π/2)  ·  sina = cos(a − π/2)
ejθ = cosθ + j sinθ  ·  cosθ = (ejθ + e−jθ)/2  ·  sinθ = (ejθ − e−jθ)/2j

Pick an identity and move a and b: the two sides trace the same curve, and the numbers agree to machine precision.
